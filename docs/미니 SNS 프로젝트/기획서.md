# 모바일 서비스 UI 기획서

## 1. 서비스 기본 정보
- **서비스 이름**: I'tel
- **서비스 주제**: IT기기 관련 SNS
- **핵심 가치**: IT기기의 최신 정보를 유저들과 함께 공유하고 또 같이 생각해보는 커뮤니티형 SNS
- **타겟 사용자**: IT기기에 관심이 많은 누구나

## 2. 디자인 컨셉
- **메인 색상**: 메탈릭 실버 및 다크 실버
- **보조 색상**: 레드
- **전체 분위기**: 모던하고 깔끔한 디자인이며 전문적인 느낌
- **참고 사이트**: Instagram(카드형 피드·무한스크롤 UX), Threads(텍스트+이미지 커뮤니티 톤), 클리앙/뽐뿌(IT기기 리뷰·정보공유 커뮤니티 정서)

## 3. 필요한 페이지 목록

### ✅ 1. 로그인/회원가입 페이지
- **기능**: 이메일 로그인 + 패스워드 로그인 / 이메일 회원가입(이메일 인증 X) / 닉네임(이름) / 생년월일(만 14세 미만 가입 금지) / 자동 로그인(토큰 저장)
- **특징**: 별명 또는 id 형식의 별명을 가진다 / 로그인 성공 시 메인으로 이동 / 로그아웃 시 로그인으로 이동

### ✅ 2. 메인 페이지 (홈 화면)
- **기능**: 무한 스크롤 / 게시물 좋아요·댓글·공유 / pull to refresh / 탐색 탭 전환 / 추천 게시물 / 사람들의 하루 꿀팁(24시간 뒤 사라짐)
- **특징**: 누구나 보기 편하고 접근성이 좋아야 한다 / 사용성이 좋아야 함 / 카드형 피드 / 더블 탭으로 추천 / 스크롤 방향에 따라 탭바 숨김 표시

### ✅ 3. 게시물 목록 페이지
- **기능**: 그리드 형식으로 보여짐 / 버튼을 눌러 그리드의 개수를 전환 / 검색기능(닉네임, 아이디, 게시물 통합) / 알고리즘으로 추천하는 게시물
- **특징**: 팔로잉이 아닌 다른 몰랐던 사람, 소식도 받아볼 수 있는 탭

### ✅ 4. 게시물 상세 페이지
- **기능**: 여러 요소 열람 가능(댓글 및 작성자의 정보) / 신고·차단
- **특징**: 카드가 확대되면서 그 카드가 게시물 상세 페이지가 된다

### ✅ 5. 게시물 작성 페이지
- **기능**: 이미지 추가 / 영상 추가 / 게시물 제목 또는 캡션 / 위치를 기반으로 한 추천 장소(ex: 저렴하게 IT기기 구매할 수 있는 곳) 공유
- **특징**: 본인의 IT기기 별점 / 추천과 비추천 탭

### ✅ 6. 마이페이지
- **기능**: 내가 올린 게시글 및 나의 게시글 수 / 나의 팔로워 수 / 내가 팔로잉한 사람의 수 / 추천한 IT기기의 수와 비추천한 IT기기 수
- **특징**: 누구나 유저의 프로필을 열람할 수 있다. 단, 로그인 시 열람 가능

### ✅ 7. 추가 페이지 (단체 채팅방)
- **기능**: 여러 세션으로 나뉜 정보 또는 자유 채팅방 / 사진 전송 가능 / 위치 공유 가능 / 채팅하는 유저들의 프로필 사진 및 프로필 사진 터치 시 그 유저의 프로필로 이동
- **특징**: 욕설 시 채팅금지 일주일 → 1개월 → 영구 정지(경고 3회 후) / 성적인 사진 및 성희롱 시 경고 없이 바로 영구 정지

## 4. 핵심 기능 정의

**필수 기능 (꼭 있어야 하는 기능)**
1. 회원가입 / 로그인 (이메일+패스워드, 자동 로그인) — 서비스 이용의 전제 조건
2. 게시물 작성 및 피드 열람 (이미지/영상 업로드, 무한 스크롤, 좋아요·댓글) — 서비스의 핵심 콘텐츠 순환 구조
3. 마이페이지 (내 게시글/좋아요 목록, 팔로워·팔로잉, 프로필 열람) — 사용자 활동 확인 및 정체성 표현

**부가 기능 (있으면 좋은 기능)**
1. PWA
2. 욕설 및 신고 누적 시 회원 탈퇴
3. 신고 / 차단
4. GPS

## 5. 모바일 UI 특징
- **네비게이션**: 하단 탭 바 (홈 / 탐색·목록 / 글쓰기 / 알림 / 마이페이지, 5개 아이콘). 메인 페이지 특징의 "스크롤 방향에 따라 탭바 숨김 표시"와 연동
- **주요 버튼 위치**: 글쓰기(작성) 버튼은 하단 탭 바 중앙에 배치, 좋아요·댓글·공유 버튼은 각 게시물 카드 하단에 가로로 배치
- **터치 영역 크기**: 최소 44x44pt(iOS) / 48x48dp(Android) 이상 확보. 좋아요·댓글처럼 자주 쓰는 버튼은 여유 있게 크게
- **세로/가로 모드**: 기본은 세로 모드 고정. 영상을 전체화면으로 재생할 때만 가로 모드 회전을 허용

## 6. 개발 우선순위
- **1차 개발(MVP)**: 로그인/회원가입, 메인 피드(무한 스크롤, 카드형 게시물, 좋아요·댓글), 게시물 작성(이미지 업로드, 캡션), 게시물 상세, 마이페이지(내 게시글·팔로워/팔로잉 수)
- **2차 개발**: 게시물 목록 페이지(그리드 전환, 검색, 추천 알고리즘), 신고/차단, 하루 꿀팁(24시간 후 자동 삭제), pull to refresh, 영상 업로드, 위치 기반 추천 장소 공유
- **3차 개발**: 단체 채팅방, PWA, GPS 활용 기능 고도화, IT기기 추천/비추천 통계 및 랭킹

## 7. 기타 결정 사항
- **생년월일**: 만 14세 이상 여부 검증에만 사용하고, 프로필 화면에는 노출하지 않는다.
- **소셜 로그인**: MVP(1차)에서는 지원하지 않고 이메일 로그인만 제공. 필요성이 확인되면 2차 이후 검토.
- **이미지/영상 저장소**: 프로토타입 단계에서는 Unsplash API로 랜덤 이미지를 선택해 게시물 이미지로 사용한다(임시). 영상 업로드는 Unsplash로 대체할 수 없어 당분간 보류한다. 실제 서비스로 전환할 때 Supabase Storage 업로드 방식(이미지 최대 10MB, 영상 최대 100MB·60초 제한)으로 교체할 예정이다.
- **하루 꿀팁(스토리)**: `created_at` 기준 24시간이 지나면 피드/목록 조회에서 자동으로 제외한다(완전 삭제는 하지 않고 숨김 처리). 다시 올리고 싶으면 새 글로 재작성한다.
- **검색 결과 정렬**: 기본값은 관련도순. 결과가 없으면 "검색 결과가 없습니다" 빈 상태 문구를 보여준다.
- **위치 공유**: 자동으로 GPS를 수집하지 않고, 게시물 작성 시 사용자가 장소를 직접 검색해 선택한다. 위치 정보를 수집·이용하므로 개인정보처리방침에 목적과 보관 기간을 명시한다.
- **단체 채팅방·신고 처리 관리자 페이지**: 3차 개발 범위로 확정한다.
- **기술 스택**: React + Vite + MUI(프론트엔드), Supabase(DB·인증·Storage), GitHub Pages + GitHub Actions(배포) — 프로젝트 표준 스택(`new_project.md`)을 그대로 따른다.
