# Contact 세션 기획서 (최종본)

> 원본 체크리스트(`contact 세션 기획.txt`)의 논의 결과를 정리해 확정한 버전입니다.

## 1. 개요
- **섹션 이름**: Contact
- **목적**: 방문자가 포트폴리오 소유자에게 연락하거나 방명록을 남길 수 있는 공간 제공
- **전체적인 느낌**: 모던하고 세련된 느낌
- **참고 이미지**: `/docs/포트폴리오/image.png`

## 2. 레이아웃

전체 배치는 위-아래 2단 구조로 확정합니다.

| 순서 | 영역 |
|---|---|
| 1 | 연락처(이메일/SNS) 영역 |
| 2 | 방명록 영역 |

## 3. UI 컨셉 및 스타일

### 3-1. 연락처 표시 방법
- 아이콘 + 텍스트를 나란히 정렬해서 보여주는 방식

### 3-2. SNS 링크 스타일
- 작은 아이콘들을 한 줄로 정렬

### 3-3. 색상 분위기
- 검정/흰색/회색 기반의 무채색(심플) 톤

### 3-4. 디자인 방향
- **꼭 포함할 요소**: 깔끔함, 나를 더 잘 알릴 수 있는 요소
- **피해야 할 스타일**: 난해한 디자인, 너무 많은 요소

## 4. 방명록(Guestbook) 데이터 구조

### 4-1. 필수 정보
- 방명록 ID (자동 생성 번호)
- 작성자 이름
- 방명록 내용/메시지
- 작성 일시

### 4-2. 연락처 정보 (선택 입력)
- 이메일 주소 — **비공개로 저장** (관리자만 조회 가능, 화면에는 노출하지 않음)

### 4-3. 추가 정보
- 거주 지역 (시/도 단위까지만)
- 나이대 (예: 20대, 30대 등)

### 4-4. 개성 표현 정보
- 이모지 선택

## 5. 미포함/보류 항목

| 항목 | 상태 | 비고 |
|---|---|---|
| 전화번호 | 보류 | 수집 여부 추가 논의 필요 |
| SNS 계정 (인스타, 트위터 등) | 미포함 | |
| 소속/직업 | 미포함 | |
| 어떻게 알게 되었는지 | 미포함 | |
| 좋아하는 색깔 | 미포함 | |
| 한마디 키워드 | 미포함 | |
| 별점 평가 | 미포함 | |

## 6. 확정 사항
- 레이아웃은 **연락처 영역 → 방명록 영역** 순서의 세로 배치로 확정한다.
- 색상은 무채색(검정/흰색/회색) 톤으로 통일하며, 별도의 포인트 컬러는 사용하지 않는다.
- 방명록에 입력받는 이메일은 화면에 노출하지 않고 비공개로 저장한다.
- 전화번호 수집 여부는 보류 상태이며, 구현 전 추가 논의가 필요하다.
