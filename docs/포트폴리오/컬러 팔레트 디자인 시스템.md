## CSS 변수 정의
```css
:root {
  /* Primary Colors */
  --color-primary: #E1251B;
  --color-primary-light: #FF4B3E;
  --color-primary-dark: #A81810;

  /* Secondary Colors */
  --color-secondary: #1B2A4A;
  --color-accent: #F2E205;

  /* Background Colors */
  --color-bg-primary: #0E1830;
  --color-bg-secondary: #2E4258;

  /* Text Colors */
  --color-text-primary: #FFFFFF;
  --color-text-secondary: #B8C4CE;
  --color-text-muted: #8A96A3;

  /* Interactive Colors */
  --color-button-primary: #E1251B;
  --color-button-hover: #FF4B3E;
  --color-link: #F2E205;
  --color-link-hover: #FFEB70;
}
```

## 컬러 사용 가이드

### Primary Colors
- **`--color-primary` (#E1251B)**: 브랜드를 대표하는 핵심 레드. 로고, 메인 CTA 버튼, 강조 배지 등 사용자의 시선을 가장 먼저 끌어야 하는 요소에만 제한적으로 사용합니다. 화면 전체 면적의 10~15% 이내로 유지해야 임팩트가 유지됩니다.
- **`--color-primary-light` (#FF4B3E)**: 버튼 hover, 활성화(active) 상태, 포커스 링 등 인터랙션 피드백에 사용합니다.
- **`--color-primary-dark` (#A81810)**: 버튼 pressed 상태, 그림자와 맞닿는 부분의 딥톤, 또는 다크 배경 위에서 레드 계열의 깊이감을 표현할 때 사용합니다.

### Secondary & Accent
- **`--color-secondary` (#1B2A4A)**: 섹션 구분 배경, 카드/패널 배경, 헤더·푸터 배경 등 넓은 면적을 차분하게 채울 때 사용하는 서브 컬러입니다.
- **`--color-accent` (#F2E205)**: 링크, 아이콘 하이라이트, 배지의 텍스트 강조 등 "레드를 쓸 수 없지만 눈에 띄어야 하는" 요소에 사용합니다. 좁은 영역(밑줄, 아이콘, 태그 텍스트)에만 사용하여 화면이 산만해지지 않도록 합니다.

### Background Colors
- **`--color-bg-primary` (#0E1830)**: 페이지 최상위 배경색. 히어로 섹션, 풀스크린 배경 등 사이트의 기본 톤을 결정합니다.
- **`--color-bg-secondary` (#2E4258)**: 카드, 모달, 섹션 구분 배경 등 배경보다 한 단계 밝은 레이어가 필요할 때 사용합니다.

### Text Colors
- **`--color-text-primary` (#FFFFFF)**: 제목, 본문 등 가장 중요한 텍스트. 어두운 배경 위에서 최대 대비를 제공합니다.
- **`--color-text-secondary` (#B8C4CE)**: 설명문, 서브 카피 등 본문보다 우선순위가 낮은 텍스트.
- **`--color-text-muted` (#8A96A3)**: 라벨, 캡션, 메타 정보(날짜, 태그명 등) 등 가장 낮은 우선순위의 보조 텍스트.

### Interactive Colors
- **`--color-button-primary` (#E1251B)**: 주요 액션 버튼(제출, 다음 단계 등)의 기본 배경색.
- **`--color-button-hover` (#FF4B3E)**: 버튼에 마우스를 올렸을 때의 배경색. 클릭 가능함을 명확히 인지시킵니다.
- **`--color-link` (#F2E205)**: 텍스트 링크의 기본 색상. 다크 배경 위에서 충분한 대비를 확보합니다.
- **`--color-link-hover` (#FFEB70)**: 링크 hover 시 밝기를 높여 인터랙션 피드백을 줍니다.

## 반응형 고려사항

### 다크모드 대응
이 팔레트는 원본 이미지 자체가 다크 톤(네이비 배경)이므로 기본 테마가 이미 다크모드에 가깝습니다. 라이트모드를 별도로 지원해야 한다면 아래와 같이 배경/텍스트 컬러만 반전시키고, Primary(레드)·Accent(옐로우)는 그대로 유지하는 것을 권장합니다.

```css
[data-theme="light"] {
  --color-bg-primary: #FFFFFF;
  --color-bg-secondary: #F2F4F7;
  --color-text-primary: #1B2A4A;
  --color-text-secondary: #4C6478;
  --color-text-muted: #8A96A3;
}
```

### 화면 크기별 고려사항
- **모바일(~480px)**: 좁은 화면에서는 `--color-primary`의 사용 면적이 상대적으로 커 보일 수 있으므로, 버튼·배지 등 작은 컴포넌트 단위로만 사용하고 배경 전체에는 적용하지 않습니다.
- **태블릿/데스크톱(768px~)**: 히어로 섹션 등 넓은 영역에 `--color-bg-primary`의 그라데이션(예: `#0E1830 → #2E4258`)을 적용해 원본 이미지의 깊이감을 재현할 수 있습니다.

### 접근성(Contrast) 체크
- `--color-text-primary` (#FFFFFF) on `--color-bg-primary` (#0E1830): 명암비 약 17:1 — WCAG AAA 통과
- `--color-text-secondary` (#B8C4CE) on `--color-bg-primary` (#0E1830): 명암비 약 9.5:1 — WCAG AAA 통과
- `--color-link` (#F2E205) on `--color-bg-primary` (#0E1830): 명암비 약 13:1 — WCAG AAA 통과
- `--color-primary` (#E1251B)를 밝은 배경(`--color-bg-secondary` 이상)에 텍스트로 사용할 경우 명암비가 낮아질 수 있으므로, 텍스트보다는 배경/아이콘 색상으로 우선 사용할 것을 권장합니다.
