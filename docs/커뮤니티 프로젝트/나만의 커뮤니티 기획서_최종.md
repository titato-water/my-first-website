# 나만의 커뮤니티 기획서 (최종본)

> 원본 기획서(`나만의 커뮤니티 기획서.txt`)와 보완점(`기획서_보완점.md`) 검토 결과를 반영해 확정한 버전입니다.

## 1. 프로젝트 개요
- **사이트 이름**: Devision
- **커뮤니티 주제**: 프론트엔드 코딩 커뮤니티
- **색상 테마**: 다크 테마 (어두운 프론트엔드 느낌)
- **분위기**: 차분한
- **참고 사이트**: https://velog.io/

## 2. 개발 우선순위 (MVP 단계 구분)

| 단계 | 포함 기능 |
|---|---|
| **1차 (MVP)** | 로그인/회원가입, 게시글 작성·수정·목록·상세, 코드 하이라이팅, 좋아요, 댓글 |
| **2차** | 팔로우, 알림, 대댓글, 카테고리/태그 필터링, 검색 |
| **3차 (확장)** | 신고/차단, 관리자 페이지, 소셜 로그인(GitHub) |

## 3. 페이지별 상세 기획

### 3-1. 로그인 페이지
- 이메일(계정) 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 버튼
- 비밀번호 찾기 버튼
  - 흐름: 등록된 이메일 입력 → 재설정 링크 발송 → 새 비밀번호 설정

### 3-2. 회원가입 페이지
- 이메일(계정)
  - **별도 인증 메일 발송 없이, 이메일 중복 여부만 검사하여 가입 진행** (확정)
- 비밀번호
- 비밀번호 확인
- 닉네임(이름)
- ~~전화번호~~ → **삭제** (개인정보 과다 수집 방지, 가입 장벽 완화)
- 회원가입 버튼

### 3-3. 마이페이지
- 프로필 카드
- 작성한 게시글
- 작성한 댓글
- 좋아요 누른 게시글
- 좋아요 누른 댓글
- 팔로우 / 팔로워 목록

### 3-4. 게시글 작성/수정 페이지 *(신규 추가)*
- 제목
- 카테고리/태그 선택 (예: 코드 리뷰, JS 문제풀이, 잡담 등)
- 본문: Markdown 에디터 + **코드 블록 문법 강조**(Prism.js 또는 highlight.js 등 적용)
- 등록 / 수정 버튼

### 3-5. 게시물 목록
- 검색: 제목 + 본문 + 작성자 + 태그 범위로 검색
- 카테고리/태그 필터 탭
- 팔로우한 사람의 게시글
  - 최신 글
  - 인기 글
- 인기 게시물 (정렬 기준: 좋아요 수 + 댓글 수 가중치, 최근 기간 내 활동 우선)
- 최신 게시물
- 목록 탐색 방식: **무한 스크롤**
- 게시글 카드
  - 코드/게시글 제목
  - 작성자
  - 작성 날짜
  - 태그
  - 댓글 수
  - 인기 댓글(3개)

### 3-6. 게시물 상세
- 게시글 제목 / 태그
- 작성자
- 작성 날짜
- 게시글 본문 (코드 하이라이팅 적용)
- 좋아요 수 + 좋아요 버튼
  - 중복 클릭 방지, 좋아요 취소 가능
  - 비로그인 상태에서 클릭 시 로그인 페이지로 유도
- 댓글 영역

### 3-7. 댓글 기능
- 댓글 작성
- 댓글 좋아요
- 대댓글

### 3-8. 알림 *(신규 추가)*
- 알림 대상: 좋아요, 댓글, 대댓글, 팔로우
- 헤더 알림 아이콘 + 알림 드롭다운/알림 페이지

### 3-9. 기타 페이지 *(신규 추가)*
- 이용약관 / 개인정보처리방침 페이지
- 404 페이지
- 빈 상태(empty state) 화면: 검색 결과 없음, 팔로워 없음, 게시글 없음 등

## 4. 향후 확장 기능 (3차)
- 게시글/댓글 신고 버튼
- 유저 차단 기능
- 관리자 페이지 (신고 처리, 유저 제재)
- 소셜 로그인 (GitHub 등)

## 5. 디자인 가이드
- 다크 테마 기반, 별도 컬러 팔레트 문서로 Primary/Background/Text 색상 정의 예정
- 반응형(모바일) 대응 고려
